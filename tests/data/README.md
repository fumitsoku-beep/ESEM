# Benchmark data provenance

This folder stores raw CSV copies used for SEM benchmark tests.

Included datasets:

- `benchmark_hs1939_raw.csv`
- `benchmark_political_democracy_raw.csv`

For each dataset, a matching `reference.json` file records:

- upstream package and documentation URL
- source note from upstream documentation
- original academic references
- intended benchmark model
- reuse/provenance notes

Important note:

- These datasets are treated here as **publicly available benchmark/example data**.
- They are **not labeled as public domain** in this repository unless upstream documentation explicitly establishes that status.
- Please preserve source and citation metadata when reusing these files.
