# Security Policy

## Supported Versions

During the current alpha stage, security fixes are provided on a best-effort basis for the latest state of the `main` branch.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please do not open a public issue first.

Instead:

1. Prepare a minimal description of the issue, affected files or features, and potential impact.
2. Include reproduction steps if available.
3. Report it privately through the repository maintainer's preferred private channel.

If no private contact channel has been published yet, open a GitHub issue only for non-sensitive coordination and avoid including exploit details.

## Response Expectations

The project is currently maintained as an early-stage research and engineering package. Response times may vary, but reports will be reviewed as quickly as practical.
