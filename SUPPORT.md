# Support

## Getting help

For usage questions, design discussions, and roadmap ideas, prefer GitHub Issues or Discussions if enabled for the repository.

## Before opening an issue

Please include:

1. A minimal reproducible example.
2. Your Python version and operating system.
3. The `psysem` version or commit hash.
4. Relevant logs or traceback output.

## Scope

This project is currently in an alpha stage. Some APIs are still evolving, especially around SEM and ESEM workflows.
